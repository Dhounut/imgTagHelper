IMGTAGHELPER
------------------------

Documentation:
	IMGTAGHELPER has 2 modes, GET and SET
		-GET: gathers all image tags from submitted folder into a txt document
		-SET: writes tags off the txt document to images in submitted folder, used for transferring tags from HR to LR
	There is only ever one txt document, so make sure you check its contents before doing anything

!!!!!WARNINGS!!!!!
-PLEASE make sure the txt file has the correct tags before attempting to SET tags
-ALWAYS double check information

Tools used-
exiftool
